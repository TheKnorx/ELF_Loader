# ELF_Loader
A simple implementation of a ELF binary loader, inspired by the 
[linux kernel function `load_elf_binary` at binfmt_elf.c](https://github.com/torvalds/linux/blob/master/fs/binfmt_elf.c)

```C
/*

*/
```
